# UFO Music Group Website Concept

An independent website concept exploring a possible digital home for UFO Music Group. Built with Next.js, React, TypeScript and Tailwind CSS.

## Concept direction

- Editorial, music-culture visual language
- Responsive layout for desktop and mobile
- Featured event concept inspired by the publicly shared "Dreams Do Come True / Ocean Drive" flyer
- Proposed sections for artists, sound, community and collaboration
- Clear concept disclaimer so this preview is not mistaken for an approved official website

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Before any official launch

This is a speculative concept, not an official UFO Music Group website. Confirm the brand's permission, event details, official social links, contact details, imagery rights and all copy before presenting it as official. The current contact email is a placeholder and should be replaced with a confirmed channel.

## Deploy

Import this repository into Vercel. The project uses the Next.js framework and can be deployed with the default build settings.
